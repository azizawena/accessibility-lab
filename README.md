# accessibility-lab

Pequenos cenários verificáveis de acessibilidade para interface web.

## Demos

- `focus.html` — foco visível e ordem de tab;
- `reduced-motion.html` — respeito a `prefers-reduced-motion`;
- `form.html` — labels, instruções, erros e autocomplete;
- `semantics.html` — landmarks e hierarquia de headings.

Abra os arquivos diretamente no navegador e teste com teclado.
